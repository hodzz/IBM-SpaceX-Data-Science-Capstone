# IBM SpaceX Data Science Capstone

This repository contains my completed IBM Applied Data Science Capstone project.

## Project Objective

The project analyses SpaceX Falcon 9 launch data and predicts whether the first-stage booster will land successfully.

## Project Workflow

- Data collection using the SpaceX API
- Web scraping using BeautifulSoup
- Data cleaning and wrangling
- Exploratory data analysis using Python visualizations
- Exploratory data analysis using SQL
- Interactive mapping using Folium
- Dashboard development using Plotly Dash
- Machine-learning classification

## Machine-Learning Models

- Logistic Regression
- Support Vector Machine
- Decision Tree
- K-Nearest Neighbours

## Repository Files

- SpaceX API data collection notebook
- Web-scraping notebook
- Data-wrangling notebook
- EDA visualization notebook
- SQL analysis notebook
- Folium map notebook
- Plotly Dash application
